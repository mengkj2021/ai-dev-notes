# 阶段 ③ · 画面测试用例

> 依据 [`project-docs/画面/`](../../../../project-docs/画面/README.md) 的**真机 / 手工**全面测试用例。  
> 原则：**考察方向要全**（主路径 / 边界 / 负向 / 回归点 / 交叉）；**不写无信息量的重复勾**（如每个子画面再勾一遍「返回回上级」——见公共约定）。  
> 缺陷起 Bug/V 挂 [待对应](../待对应.md)。非自动化单测。

## 用法

1. 按索引打开画面文件；每条 `- [ ]` → 通过 `- [x]`；失败补备注并起票  
2. 一条 = 一个可独立判定的检查点；长路径可拆，但不要拆成「同一步重复勾两次」  
3. 记录构建 `versionName`、机型、系统  
4. **全部用例已 `[x]`** 的画面 → 移入 [`已通过/`](已通过/)，并改本索引链接

## 公共约定（全局，不逐画面重复勾）

| 项 | 说明 |
|---|---|
| 返回默认 | 有上级的画面：顶栏 / 系统 / 手势 → 安全 `pop` 回上级；不二次 pop 卸 `main`（Bug6 / Bug10） |
| 空态默认 | 列表空 / 筛选无命中：有文案、无崩溃 |
| FAB 列表 | 有 FAB 的可滚列表：末项不被挡（Bug9） |
| 语言 | 简中全量；日/英抽关键文案 |
| 压缩参数 | 现行实现约 2MB / 1920px / JPEG≈85（`ImageManager`）；未单独起票定稿前勿当最终式样 |

**例外**：该画面返回/空态有**特殊规则**时（导入中拦截、首次教程根返回退出、筛选未应用不回传等）必须单独写用例。
