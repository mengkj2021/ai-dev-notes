## 主图缩放（F4 / S8）

- [x] **DT-10** 双指捏合放大约 1x～5x，可平移
- [x] **DT-11** 双击主图 → 回 1x 并居中
- [x] **DT-12** scale>1 → 重命名/标签区隐藏；回 1x → 编辑区显示（S8：单击主图**不**切换显示）
- [x] **DT-15** 缩略条切换图片 → 缩放重置为 1x

## 重命名

- [x] **DT-20** 改主名 →「重命名」：物理文件 + DB（fileName/path/description）更新
- [x] **DT-21** 扩展名只读展示，不可改后缀（F2）
- [x] **DT-22** 主名全删后失焦 → 恢复进入编辑前的原主名（F2）
- [x] **DT-23** 空名 / 非法字符 / 同目录重名 → Snackbar 失败，不破坏原文件
- [x] **DT-25** 「套用重命名模板」：立即改名；扩展名锁定
- [x] **DT-26** 模板 `{date}` / 年月日：拍摄日优先，无则导入日（F34/F45）
- [x] **DT-27** 无模板时「套用重命名模板」禁用



## 标签

- [x] **DT-30** 库标签 ≤10：主区平铺 Chip；点选加减并保存；不含状态名
- [x] **DT-31** 库标签 >10：主区仅已选 +「选择标签」BottomSheet；面板内即时勾选（F9）
- [x] **DT-32** >10 时主区点已选 Chip 可取消
- [x] **DT-33** 自由输入新标签「保存」→ 写入图片，成功后入库（S2）
- [x] **DT-34** 自定义（非库）Chip：可编辑 / 关闭删除
- [x] **DT-35** 「套用模板」选 B（先前已套 A）→ **覆盖**为 B，不保留手选并集（F39）
- [x] **DT-36** 无标签模板时套用入口禁用或提示
- [x] **DT-37**（可选）Exif 写失败时：DB 仍成功 + Snackbar 提示



## 缩略条

- [x] **DT-40** 仅展示当前 `ImageStatus` 下图片
- [x] **DT-41** 当前项描边高亮；点击切换后主图 / 文件名 / 标签 / 拍摄日同步



## 状态操作（F30 / S9）

- [x] **DT-50** 待归档「更多」：可移动到已归档 / 回收站；**无**「删除」
- [x] **DT-51** 已归档「更多」：可移动到待归档 / 回收站；无「删除」
- [x] **DT-52** 回收站「更多」：可移动到待归档 / 已归档；有「删除」
- [x] **DT-53** 移动成功：切到同原状态缩略条下一张（无下一张则前一张）
- [x] **DT-54** 同状态全量已无其它图：移动后返回主画面一览（Bug19）
- [x] **DT-55** 回收站「删除」须确认；确认后真删文件+DB → 回一览；取消不删
- [x] **DT-56**（S9）筛选后一览仅 1 张、同状态全量仍有其它 → 进详情（条仍可多张）→ 移走当前 → **切全量下一张**，不因筛选仅 1 而回一览
- [x] **DT-57**（S9）筛选后一览仍有多张 → 移走当前 → 切全量下一张（可落在筛选外）；仅全量空才回一览
