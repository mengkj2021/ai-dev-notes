> **定位**：以后生成任何文档都按本文。

## 0. AI 开发闭环

先选车道（产品或体系），再改对应目录。体系和例子解耦。

```
prompts/         拉入对话的编排壳
shared/          rules · skills 编排壳（同步到工具）
    ↕ ▶ include
ai-workbench/    指南 / 宪法 / 细则 / 模板 / 错题本
    ↓ 读取
examples/project-docs/                    共享产品规格
examples/project-status/<android|windows>/
ai-workbench/体系/                        笔记层票
    ↓ 变更
examples/<android|windows>/      例子代码（体系票则改 prompts/ · shared/ · ai-workbench/）
    ↓ 写回
examples/project-docs/ · 该车道 status
```

| 环节 | 目录 | 职责 |
|---|---|---|
| 怎么干 | `prompts/` · `shared/` | 编排壳；rules / skills |
| 干活材料 + AI 元文档 | `ai-workbench/` | 指南 · 宪法 · 细则 · 模板 · 错题本（**不是**产品规格） |
| 读什么 | `examples/project-docs/` · 该车道 status | 规格；该车道票与是否实现 |
| 改什么 | `examples/<车道>/` 或笔记层目录 | 当前接票目标 |
| 写回什么 | 同上 docs + 该车道 status | 过程写在票内 |

禁止颠倒：不把产品规格写进 `prompts/` / `shared/` / `ai-workbench/`；不把 AI 纪律写成 `project-docs` 正文。

**现默认例子 = Android**（`examples/android/`）。`create-screen-doc` / `implement-screen` 只服务该例子。Windows 技能未建。

## 4. 拆 / 不拆门槛

命中 **≥2 条**才把一篇长文拆成「短索引 + 分册」：

1. 单文件明显变长，且含 ≥3 个可独立读的主题
2. 接票经常只需要其中一章
3. 已有自然章节边界

**不拆**：单主题短文；时间线（单张票）；已是一目录一主题；高频锚点（架构 **§2** 仍在 `examples/project-docs/架构设计.md`）。

不删内容，只搬家。权威入口文件名不改。`examples/project-docs/` 与 `examples/project-status/` 迁完后根上不再留同名跳转目录。

## 5. 索引页与分册写法

### 5.1 索引

1. 文首「AI 阅读入口」3～7 条
2. 每章：2～5 行摘要 + **位置**
3. 高频锚点可全文留在索引

### 5.2 分册

- 保留原节号
- `examples/project-docs/` 用直白名
- 分册开头一行：所属索引路径（整理期可省略）

## 6. 各类生成模板

| 类型 | 怎么生成 |
|---|---|
| 式样 / 设计说明 | 索引 + 按门槛分册；落 `examples/project-docs/`（两端差写差异表或文内标注） |
| 画面 | 复制 [模板/画面文档/](../模板/画面文档/) → `examples/project-docs/画面/<名>/`；技能 `create-screen-doc`（**仅 Android 例子**） |
| 票 | 复制 [模板/票/](../模板/票/) → 产品 `examples/project-status/<端>/票库/…` 或笔记 `ai-workbench/体系/票库/…` |
| 过程记录 | 写在票「开发记录 / 完结复盘」 |
| AI 元文档 | 落 `ai-workbench/宪法/` 或 `指南/`，并回写落位盘点表 |
| AI 通识笔记 | [`指南/通识/`](../指南/通识/00-目录.md) |
| GitHub 前沿摘录 | [`指南/GitHub收集/`](../指南/GitHub收集/00-目录.md)；要 SOP 须另起**体系**票迁入 |
| 提示词 / rules / skills **编排壳** | 落 `prompts/` 或 `shared/` |
| 细则正文 | 落 `ai-workbench/细则/` |

## 7. 读法（给人 / 给 AI）

1. 先选车道 + 票或 prompt 填写区 → 再按 §0 闭环选读
2. 打开该层入口 README，**不通读**整库
3. 打开权威索引，按「位置」只开需要的分册
4. 禁止把式样 / 架构 / 本宪法全文粘进 alwaysApply rules
