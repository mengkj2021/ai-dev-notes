# 票代号与节点（起票约定）

> **模板 / 约定**：起票时填「所属节点 / 涉及节点」。阶段进度见各车道 [`examples/project-status/`](../../../examples/project-status/README.md)，**不**在本文件跟踪现状。

## 代号

| 代号 | 含义 | 与生命周期 |
|---|---|---|
| **B** | 奠基 | 主要落在阶段 ① |
| **V** | 打磨 / 修 bug / 体验 | 主要落在阶段 ②；公开后按需仍可用 |
| **P** | 公开准备 | 落在阶段 ② 后半 |

## 填写规则

1. **票号**全局不重置（`Bug` / `S` / `T` / `F`）；❌ 号不复用。  
2. 填 **所属节点**（主归属）；跨阶段时填 **涉及节点**，主归属与标题前缀改挂**最新**节点。  
3. 展示标题可用 `V · 〈原标题〉`（或 `B` / `P`）。  
4. **目录名**为 `票号-简述`，**不含**节点代号。  
5. 定节点提示：打磨 / 修 bug → `V`；公开包装 / 仓约定 → `P`；奠基史 → `B`。

票库总规则：先选 [车道](../../../examples/project-status/README.md)。
