# GitHub 收集 · 细则

> 供 `prompts/收集_GitHub.md` ▶ include。  
> 只改 `ai-workbench/指南/GitHub收集/`。**不**把摘录写进 rules / skills / 接票细则。

1. **读入口**  
   - 打开 [`指南/GitHub收集/00-目录.md`](../../指南/GitHub收集/00-目录.md)  
   - 已有条目不重复堆；同一 URL 已有则更新一两句，不另开行

2. **读填写区**  
   - 有 URL：按链接取公开页标题与摘要（能打开再写；打不开则只记 URL + 「未打开」）  
   - 只有主题：用公开检索找相关仓库 / SKILL.md / 资讯，**标明来源 URL**  
   - 条数上限：填写区数字，缺省最多 **8** 条  
   - 分区：`仓库` / `skills` / `资讯`；填了分区则只写该表

3. **怎么写一条**  
   - 日期（今天）· URL · 一两句「对本仓有没有用」  
   - 长文只摘要，不整页粘贴、不整仓复制  
   - 对本仓可能有用：写「若要落地 → 另起体系票迁入 `prompts/` / `shared/` / 细则」，**本轮不迁**

4. **写回**  
   - 只改 `00-目录.md` 对应表；保持三表结构  
   - 文首「尚未收集」在有第一条后删掉  
   - 不改宪法正文（除非目录约定变了）  
   - 不 commit（除非用户另拉提交壳）

5. **禁止**  
   - 把摘录当成接票 SOP  
   - 改 `examples/` 产品码或规格  
   - 为「好看」再建空子目录
