# 起票分析 · 细则

> 供 `prompts/票_起票分析.md` ▶ include。只落盘票，**不改代码**。产品车道：[`examples/project-status/README.md`](../../../examples/project-status/README.md)；笔记：[体系](../../体系/README.md)。

1. **读输入与票库现状**
   - 续号**只认**该车道「下一号」（android 见阶段 README；体系见 `ai-workbench/体系/阶段/README.md`；windows 见该车道 README）
   - 输入逐条归类：Bug / 式样变更 / 调查 / 功能体验；AI 层改动进**体系**车道
2. **文档优先分析**
   - 按根 README 与 [`文档分层约定.md`](../../宪法/文档分层约定.md) 定位
   - 判断类型、现状、影响、「待定」
3. **文档不足 → 定点读码**：默认 `examples/android/app/src/`
4. **归类产出**
   - 能归类 → 拟票；待定 → 调查票；无法归类 → 回问
   - ▶ include `ai-workbench/细则/接票/拆票门槛与档位.md`
5. **落盘**：复制 `ai-workbench/模板/票/` → 产品 `examples/project-status/<端>/票库/<分区>/` 或笔记 `ai-workbench/体系/票库/<分区>/`；该车道待对应加 ☐ 行；推进该车道下一号
6. **回执**：已建票清单 + 车道

**硬性约束**：一票一主题；票号只进不退；☐/🚧 必须出现在该车道待对应；只建票不改码。
