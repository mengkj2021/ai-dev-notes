# 4.4 协作：RAG 知识库集成

检索增强：提问 → Embedding 检索 Top-K 文档 → 注入上下文 → 生成回答。

## 原理

```
用户提问 → 向量检索 → Top-K 片段 → 拼入 Prompt → AI 回答
```

## 典型知识源

| 知识源 | 解决什么 |
|--------|----------|
| 内部 Wiki / 需求文档 | 业务规则不靠猜 |
| Swagger / OpenAPI | 字段与类型正确 |
| 组件库文档 | 属性与 API 用对 |
| 历史 Bug 工单 | 避免重复踩坑 |
| 团队编码规范 | 生成即合规 |

## 落地路径

1. 文档向量化（Embedding 模型）
2. 存入向量库（Pinecone / Milvus / pgvector 等）
3. MCP Server 连接 AI 工具
4. 每次提问自动检索 Top-N 片段注入上下文

## 各模式中的用途

| 模式 | RAG 用途 |
|------|----------|
| SDD | 检索相似历史 Spec |
| TDD+AI | 检索已有测试避免重复 |
| PDD | 检索组件用法 |
| Review-Driven | 对照安全/规范文档 |
| Agent-Driven | Agent 自主查项目文档 |

RAG 是**预检索**；编码 Agent 更常 JIT 搜仓库。两者可组合：静态规范走 RAG，代码走 grep。关系见 [1.1](../基础/01-基础概念.md)、[1.7](../基础/06-上下文工程.md)。
