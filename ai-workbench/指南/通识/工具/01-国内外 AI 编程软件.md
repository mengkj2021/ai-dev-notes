# 2.1 国内外 AI 编程软件

对比维度：形态、模型、价格、国内可用、Agent 能力。价格与功能以官网为准。更新于 **2026-10**。

## 国内

| 产品 | 形态 | 模型 | 价格 | Agent | 要点 |
|------|------|------|------|-------|------|
| **CodeBuddy** | IDE / 插件 / CLI | 混元、DeepSeek 等 | 基础免费 | ✅ | Skill/MCP/Team Agent；国内直连；GitHub Spec Kit 已对接 |
| Trae | 独立 IDE | Seed / GLM / 多模型 | 免费档 | ✅ | SOLO Agent、看图写代码；轻量原型 |
| Qoder | IDE + CLI | Qwen / 多模型 | 云厂商套餐 | ✅ | 阿里侧 Agent 编码；Spec Kit 支持 `qodercli` |
| 通义灵码 | 插件 + CLI | Qwen-Coder 等 | 免费/企业 | 部分 | 阿里云、Java/云原生；行间补全与 MCP |
| 文心快码 | 插件 / 企业 | 文心 5 + 多模型试用 | 免费/企业 | 部分 | 政企合规、私有化；SPEC/多 Agent |
| Kimi | Web/App + CLI | Kimi K3 等 | 免费/付费 | ✅ | 长上下文调研与 Kimi Code；K3 开源可自部署但硬件重 |
| 智谱 GLM | API / 插件 | GLM-5.3 | 按量 | 部分 | 开源权重 + API；插件生态一般 |
| **DeepSeek Harness（DSH）** | 本地 Agent CLI + 桌面 / Web GUI | DeepSeek V4 系（Flash / Pro） | 按量（API Key） | ✅ | 工作区指令读 `AGENTS.md` / `CLAUDE.md`（逐级就近）；项目件放 `.dsh/rules`、`.dsh/skills`；按需加载 Skill、子代理 / 工作流、沙箱与后台任务 |

## 国外

| 产品 | 形态 | 模型 | 价格 | Agent | 要点 |
|------|------|------|------|-------|------|
| **Cursor** | IDE + Agent 工作区 | Grok/Composer + Claude/GPT/Gemini 等 | Pro ~$20/月 | ✅ | **Cursor 3**（2026-04）本地/云 Agent、多仓、插件；**Projects**（2026-09）协调器管子代理。2026-08-14 SpaceX 全股票收购，隐含股权价值 **$60B**（不是 600B）。仍提供 OpenAI 等第三方，走 Other Models 池 |
| **Claude Code** | CLI（可嵌 VS Code） | Claude | 按 Token / 订阅 | ✅ | 规划与代码质量强；Opus 4.7+ / Fable 默认 1M；Mods / MCP / 后台子代理 |

| GitHub Copilot | IDE 插件 | 多模型 | ~$10/月起 | ✅ | 2026-09：Automations、Agent 开 PR、Dev Container 会话、跨应用续 Codex |

| Cline | VS Code 插件 | 任意 API | 开源免费 | ✅ | 可换模型、MCP；自备 Key |
| Aider | CLI | 多模型 | 开源免费 | ✅ | Git 感知、轻量 |
| JetBrains AI | IDE 内置 | 多模型 | 订阅 | 部分 | Java/Kotlin 深集成 |
| Zed AI | 编辑器内置 | 多模型 | — | 部分 | 性能好，生态尚小 |

## 按场景选型

| 场景 | 推荐 |
|------|------|
| 国内综合 | CodeBuddy；阿里栈加 Qoder/灵码 |
| 国内免费轻量 | Trae |
| 国内 Agent CLI | DeepSeek Harness（DSH），按量计费、可跑长任务 |
| 难任务 CLI | Claude Code；已有 ChatGPT 则 Codex |
| 完整 Agent 工作区 | Cursor 3 + Projects（需海外网络） |
| 不换 VS Code/JetBrains | Copilot / JetBrains AI / Cline |
| 开源自配模型 | Cline / Aider |
| 整库长文调研 | Kimi（辅助，不替代仓库 JIT 检索） |
| 规约脚手架 | GitHub Spec Kit（多 Agent 后端） |
