# 4.5 协作：Hook 机制

在 Agent 生命周期节点自动执行脚本，把质量控制从「人记得做」变成「流程必做」。

## 典型触发点

| 触发点 | 自动动作 |
|--------|----------|
| 会话开始 | 拉代码、装依赖、读 Spec/Rules |
| 编码前 | 读目标文件、检查未提交变更 |
| 编码后 | ESLint、Prettier、tsc |
| Task 完成 | 跑单测、对照验收标准 |
| 提交前 | 全量测试、变更摘要、更新 CHANGELOG |
| Shell 执行前 | 拦截危险命令（rm -rf 等） |

## 价值

- 不依赖人记得每一步检查
- Agent 模式尤其需要（人不在每步盯着）
- 用 Hook 扩展逻辑，**不改工具内置 Template 源码**（见 [1.5 避坑手册](../基础/04-AI%20开发避坑手册.md) 问题 12）

## 各模式侧重

| 模式 | Hook 重点 |
|------|-------------|
| SDD | Task 完成对照验收标准 |
| TDD+AI | 编码后自动跑测试 |
| PDD | 编码后格式化 |
| Review-Driven | 提交前安全审查 |
| Agent-Driven | 全链路 Hook，人为最后防线 |

配置见 [2.3 Cursor 使用](../工具/03-Cursor%20使用.md) Hooks 章节。
