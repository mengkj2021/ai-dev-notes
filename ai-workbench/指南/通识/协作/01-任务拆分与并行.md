# 4.1 协作：任务拆分与并行

与 [3.1 SDD](../开发模式/01-SDD%20规约驱动开发.md) 的 Task 拆分、[4.2 Team Agent](02-Team%20Agent%20多智能体.md) 的调度配合使用。

## 拆分原则

| 原则 | 说明 |
|------|------|
| 无数据依赖优先 | 纯 UI、独立接口最早并行 |
| 接口约定先行 | 先定 API 签名，前后端可并行 |
| 按页面/组件原子拆 | 一页面或一组件一 Task |
| 按功能块解耦 | 登录与设置模块独立 |

## 并行方式

| 方式 | 说明 | 适用 |
|------|------|------|
| 单 Agent 串行 | 按依赖顺序逐个执行 | 中小任务 |
| 多会话手动 | 人开多个会话或 worktree 分配分区 | 大项目、边界清晰 |
| Team Agent / Projects | 协调器拆分+分配+汇总 | 大项目、依赖复杂、跨会话 |

## 拆分粒度

| 任务规模 | 建议 |
|----------|------|
| 小页面 | 不拆，一个 Task |
| 功能模块 | 3–5 个 Task |
| 全新项目 | 10–20 个 Task，按模块与依赖 |

详见 [1.5 避坑手册](../基础/04-AI%20开发避坑手册.md) 问题 5–7（整页拆分、重复代码、公共层）。
