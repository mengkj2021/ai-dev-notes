# 4.6 协作：人在环（Human-in-the-Loop）

人是设计者、决策者、验收者；AI 是执行者。各开发模式中人的参与程度不同，但**审查与验收不可省略**。

## 分工

| 环节 | 人 | AI |
|------|-----|-----|
| 需求分析 | 功能、优先级、验收标准 | 整理结构化文档 |
| Spec/测试 | 概述、页面清单、验收 | 补充模型与边界 |
| Plan 审阅 | 确认选型与架构 | 生成方案供选 |
| 执行 | 复杂逻辑、方向纠偏 | 写代码、跑测试 |
| 验收 | 功能测试、Diff Review | 生成用例、自查 |

## 各模式参与度

| 模式 | 人参与频率 | 人主要做什么 |
|------|------------|--------------|
| PDD | 每步 | 每轮对话反馈 |
| Review-Driven | 阶段性 | 每批 Diff Review |
| SDD | 头尾 | 写 Spec + 验收 |
| TDD+AI | 头尾 | 写测试 + 验收 |
| Agent-Driven / Projects | 头尾与抽检 | 定目标、看证据、抽 Diff |

## 反模式

| 反模式 | 问题 | 正确做法 |
|--------|------|----------|
| 无 Spec/测试直接写 | AI 跑偏 | 至少 5 行约束 |
| 一次 10 个需求 | 遗漏混淆 | 一次 1–3 个 Task |
| 代码全盘接受 | 盲区与安全风险 | 必须 Diff Review |
| 让 AI 定架构 | 缺项目全貌 | 人定架构，AI 填细节 |
| 无验收标准 | 不知何时完成 | 每条 Task 有验收标准 |

Agent 信任层级见 [3.5 Agent 驱动开发](../开发模式/05-Agent%20驱动开发.md)。
