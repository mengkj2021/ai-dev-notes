## 2026-10 观察（以官方为准）

- **Agent 工作区**：Cursor 3、Copilot Agent、Claude Code / Codex CLI 并列一线
- **长任务产品化**：Cursor Projects（协调器 + 云子代理 + 事件订阅）
- **Skill 标准化**：Agent Skills 格式跨产品；MCP Skills 扩展已 Final，宿主仍在接
- **上下文工程**压过「只写 Prompt」；1M 窗口普及但 Context Rot 仍在
- **模型分池**：Cursor 自研/联合（Composer、Grok）与第三方分账单；编码榜常看 Opus 5.5 / Sonnet 5.5，便宜量大看 DeepSeek Flash
- **收购与合规**：Cursor 已交割为 SpaceX 子公司（$60B 股权价值）；Windsurf 属 OpenAI

## 选型：按项目类型

| 项目类型 | 工具 | 模型 | 模式 |
|----------|------|------|------|
| 新前端 | Cursor / CodeBuddy | Sonnet 5.5 / DeepSeek Flash | SDD（可用 Spec Kit） |
| 新后端 | Claude Code / Codex | Opus 5.5 / GPT-6.1 Sol（Codex） | TDD+AI |
| 全栈 | CodeBuddy Team 或 Cursor Projects | 混合 | SDD + 混合 |
| 存量加功能 | Cursor / Copilot | Sonnet 5.5 | Review-Driven |
| 重构迁移 | Cursor Projects / Claude Code | Opus / Grok 4.7 | Agent + 证据链 |
| 快速原型 | Cursor / Trae | Composer 2.5 / Seed | PDD |
| 个人小工具 | Trae / Codex / DeepSeek Harness | DeepSeek Flash | PDD |
| 企业大项目 | 统一 Rules + Spec Kit + 一种 CLI | 组合 | SDD + Team / Projects |

## 选型：按预算

| 预算 | 组合 | 月成本粗估 |
|------|------|------------|
| 零 | Trae + DeepSeek 免费额度 + 本地 Qwen 小尺寸 | ¥0 |
| 低（<¥100） | CodeBuddy 免费版 + DeepSeek API | ¥20–50 |
| 中（¥100–500） | Cursor Pro，优先耗尽 Composer/Grok 池 | ¥100–300 |
| 高 | Cursor Pro Plus/Ultra 或 Claude 订阅 + 第三方高峰 | ¥500+；日用多 Agent 常 $60–200+ |

定价以官网为准。Cursor 长上下文与 Fast 档有倍率。

## 选型：按团队规模

| 规模 | 建议 |
|------|------|
| 个人 | Cursor 或 Claude Code / Codex 二选一作主力 |
| 2–5 人 | 统一工具 + Git 同步 `.cursor`/`.codebuddy`/`.dsh` + Spec Kit constitution |
| 5–20 人 | Team Rules/MCP + RAG 规范库；大功能用 Projects 或 GSD |
| 20+ 人 | 多工具共存（IDE + CLI Agent）+ 文档化规范；采购需审数据处理主体 |

## 学习路径

| 阶段 | 目标 | 行动 |
|------|------|------|
| 第 1 周 | 能对话写代码 | 装 Cursor/CodeBuddy，PDD 做 Todo |
| 第 2 周 | 有规范边界 | 配 Rules，SDD 或 Spec Kit 做一个功能 |
| 第 3–4 周 | Agent 自主干活 | Skill 渐进加载、MCP（少而清）、Worktree |
| 第 2 月起 | 长任务 | 上下文工程、GSD 轻量工单、按需 Projects |

## 决策树（简版）

```
开发什么？
├── 前端 → 新项目 SDD / 存量 Review-Driven
├── 后端 → 新项目 TDD+AI / 存量 Review-Driven
└── 全栈 → 国内 CodeBuddy；海外 Cursor Projects + SDD

网络？
├── 国内 → CodeBuddy / Trae / Qoder / DeepSeek
└── 可访问海外 → Cursor / Claude Code / Codex

预算？
├── 免费 → Trae + DeepSeek
├── 中 → Cursor Pro + 自带池模型
└── 充足 → Opus 5.5 / Fable 做难任务
```
