# AI 开发框架 · 效果短结论

> 这套起票制对自己有没有用。不是对外交付说明。

## 解决了什么

1. **改动可追溯**：先有票再改；完结有复盘。
2. **文档跟代码同闭环**：接票强制文档先行；规格不进常驻 rules。
3. **人机分工清楚**：人定意图与点验；AI 接票落盘。
4. **规模可控**：拆票门槛 + 一票一会话。
5. **三工具可同步**：`shared` → `.cursor` / `.codebuddy` / `.dsh`。

## 还弱在哪

1. 点验仍靠人；Compose / 导航竞态主要靠真机。
2. 发版、clone 冒烟仍手工。
3. 票和文档多，流程偏厚。
4. skills / rules 要手同步三套工具目录，容易漏。

## 一句话

把「对话里改完就忘」收成可重复的台账；代价是厚度，测试深度仍取决于人。
