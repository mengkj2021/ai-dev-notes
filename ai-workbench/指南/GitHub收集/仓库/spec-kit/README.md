# spec-kit

**分区**：仓库 · **收集**：2026-10-03

## 简介

GitHub 开源的 Spec-Driven Development 工具箱：先写可执行规格，再让任意 coding agent 按阶段实现。核心技能/命令是 constitution → specify → plan → tasks → implement → converge，另有 bug 修复、点子评估等扩展。

## URL

https://github.com/github/spec-kit/

文档：https://github.github.io/spec-kit/

## 使用效果

按官方 README：用 `specify init` 接到 Cursor 等 agent 后，对话里跑 `/speckit.specify` 等，会在仓库里落下 spec / plan / tasks 等 Markdown，再按产物写代码；`/speckit.converge` 对照规格查漏。本仓**未安装试用**。

## 对本仓

已有票 + `examples/project-docs`，可对照「阶段产物怎么切」。**摘录≠ SOP**。若要落地 → 另起体系票迁入 `prompts/` / `shared/` / 细则。
