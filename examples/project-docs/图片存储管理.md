# 图片存储管理

> **Android 现状**：私有目录布局。Windows：未实现，见 [两端差异.md](两端差异.md)。实现：`util/file/AppFileManager` 等。全程本地、**不联网**。

| 路径 | 含义 |
|---|---|
| `filesDir/images/pending/` | 待归档（目录名不变） |
| `filesDir/images/confirmed/` | 已归档（目录名不变） |
| `filesDir/images/no_modify/` | 回收站（显示名；目录名不变） |

导入写 `pending/`；「移动到」搬文件并改库；删除 = 删文件 + 删行。导出 zip → `filesDir/exports/`（FileProvider）。

**移动约束**：物理搬移失败（含源已缺失）仍把库内相对路径改到目标状态子目录，保证路径与状态一致。

**备份**：`allowBackup=false`，配合 `backup_rules` / `data_extraction_rules`；Manifest 无网络权限。
