# 图片存储管理

> **Android 现状**：私有目录布局。**Windows 现状**：`%LOCALAPPDATA%/PictureOrganizer/` 下同名子目录。实现：两端各自 `util/file/AppFileManager`。全程本地、**不联网**。

| 相对路径 | 含义 |
|---|---|
| `images/pending/` | 待归档（目录名不变） |
| `images/confirmed/` | 已归档（目录名不变） |
| `images/no_modify/` | 回收站（显示名；目录名不变） |

| 端 | 根目录 |
|---|---|
| Android | `filesDir/` |
| Windows | `%LOCALAPPDATA%/PictureOrganizer/` |

导入写 `pending/`；「移动到」搬文件并改库；删除 = 删文件 + 删行。导出 zip → `exports/`（Android：FileProvider；Windows：阶段②）。

**移动约束**：物理搬移失败（含源已缺失）仍把库内相对路径改到目标状态子目录，保证路径与状态一致。

**备份**：Android `allowBackup=false`，配合 `backup_rules` / `data_extraction_rules`；Manifest 无网络权限。Windows 不参与云备份约定。
