# 预览区

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片打包画面 / `export-zip` |
| 区域名称 | 预览区 |
| 对应 UI | `LazyVerticalGrid` 小图 + 右上角叉 |

## 2. 功能清单

- [x] 展示当前筛选命中、且未被排除的已归档图缩略图（F41）
- [x] 小图右上角叉：从**本次**打包集合去掉该图
- [x] 排除为会话临时态（`ExportZipViewModel` 内存）；pop 出本画面后清空；进筛选再回保留
- [x] 改筛选不自动恢复已排除 id
- [x] 打包中叉不可用；剩余 0 张时「开始打包」不可用

## 3. 用户操作

1. 进入打包画面（或改筛选返回）后，预览当前将进包的图
2. 点某张右上角叉 → 该图从预览消失，不进入本次任何标签包
3. 「开始打包」只打包预览剩余项

## 4. UI 描述

- 自适应列数网格；小图裁切填充
- 叉为对比色圆形底，contentDescription 说明「从本次打包排除」
- 无剩余项时展示空态文案（筛选无命中或已全部排除）

## 5. 数据 / 事件

- 读：`ExportZipUiState.previewItems`（已筛且 `excludingIds`）
- 写：`ExportZipUiEvent.ExcludeImage`
- 进包：`buildSingleExportPack`（S7 单 zip；输入为排除后的列表）
