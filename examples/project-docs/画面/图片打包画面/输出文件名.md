# 输出文件名

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片打包画面 / `export-zip` |
| 区域名称 | 输出文件名 |
| 对应 UI | 一行 `OutlinedTextField`（stem）+ 只读后缀 `.zip` |

## 2. 功能清单

- [x] **F42 / S7**：开始打包前编辑**单个** zip 主文件名；扩展名固定 `.zip`
- [x] 默认 `export_{日期}`（日期 `yyyyMMdd`）
- [x] 用户改过的 stem 会话内保留；改筛选清空覆盖
- [x] 非法名（空、含 `/ \ : * ? " < > |`）Snackbar，不开始打包
- [x] 与 `exports/` 已有文件冲突则自动 `_2` `_3`
- [x] 打包中输入框不可用；无即将生成的包时不展示本区

## 3. 用户操作

1. 预览有剩余项后，看到默认文件名
2. （可选）改主名；不必手写 `.zip`
3. 「开始打包」→ 校验通过后按最终名落盘；结果列表与分享用该名

## 4. UI 描述

- 位于筛选行与「开始打包」之间
- label「文件名」，输入框 suffix 为 `.zip`（对齐详情重命名锁后缀）
- 输入区走画面 Scaffold 的 `imePadding`（Bug2）

## 5. 数据 / 事件

- 读：`ExportZipUiState.plannedPacks`（单元素；`label` 为内部常量，`stem` 供展示）
- 写：`ExportZipUiEvent.ZipStemChanged`
- 规则：`util/file/ExportZipNames.kt`（`validateZipStem` / `planZipFileNames` / `defaultSingleZipStem`）
