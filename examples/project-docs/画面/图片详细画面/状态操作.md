# 图片详细画面 · 状态操作（F30）

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片详细画面 / `image-detail/{imageId}` |
| 区域名称 | 状态操作 |
| 对应 UI | TopAppBar `actions` ·「更多」溢出菜单；删除确认 `AlertDialog` |

## 2. 功能清单

- [x] **F30**：TopAppBar「更多」→「移动到」各目标状态（不含当前状态）
- [x] **F30**：仅当前图 `status = 回收站` 时，「更多」内显示「删除」
- [x] **F30 / S9**：移动成功 → 跳转同状态缩略条中的下一张（无下一张则前一张）；**仅同状态全量已无其他图** → 返回主画面一览（与缩略条所见一致；不再按进入时筛选可见数提前返回）
- [x] **F30**：删除须确认；成功后返回主画面一览
- [x] 待归档 / 已归档详情不出现删除入口

## 3. 用户操作

1. 点 TopAppBar「更多」
2. 选「移动到 → 〈目标状态〉」→ 改库 + 搬文件 → 自动切到同原状态（全量）剩余图中的下一张；仅全量已无其它图时返回一览
3. （仅回收站）选「删除」→ 确认对话框 → 真删文件 + DB → 返回一览

## 4. UI 描述

- 「更多」：`MoreVert` IconButton + `DropdownMenu`
- 移动项文案：`移动到` + 目标状态显示名（与一览一致）
- 删除：确认后再执行；忙碌中菜单项禁用

## 5. 数据 / 事件

- `ImageDetailUiEvent.MoveTo(ImageStatus)` / `DeleteCurrent`
- `ImageRepository.moveItems` / `deleteItems`（与主画面同源）
- `ImageDetailUiEffect.NavigateBack`（无剩余同状态全量图 / 删除成功）
- **S9**：缩略条、「下一张」、是否回一览均只按**同状态全量**；不下发一览筛选可见数
- **删除成功**：只发 `NavigateBack`，不先发 Snackbar（Channel 上消息挂起会挡住 pop）。移动成功则「返回」与「下一张 + 提示」二选一
- **Bug19**：UI 收集 effects 时，`ShowMessage` **不得挂起挡住**后续 `NavigateBack`（连续「移一张→再移最后一张」时，上一张成功 Snackbar 若阻塞 collect，会延迟/丢失返回，条会先刷成目标状态）
- **Bug19**：程序化离开（移空 / 删除）的 pop **不经** `dropUnlessResumed`；`popRouteIfOnTop(..., requireResumed=false)`，避免非 RESUMED 静默丢弃
