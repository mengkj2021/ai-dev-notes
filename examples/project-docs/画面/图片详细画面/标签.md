# 图片详细画面 · 标签

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片详细画面 |
| 区域名称 | 标签 |
| 对应 UI | 用户标签 Chip + 标签库多选 + 套用模板 + 自由输入 |

## 2. 功能清单

- [x] 添加 / 删除 / 修改用户标签（不含状态标签）
- [x] Room `tagsJson` 真源；同步 Exif `UserComment` JSON
- [x] Exif 失败时 DB 仍成功，Snackbar 提示
- [x] 从标签库多选 Chip（**C6 · 1A**）；保留自由输入
- [x] 套用标签模板：以模板标签集**覆盖**当前用户标签（trim / 去空 / 滤保留字 / 保序去重；不保留手选）（**C6 · T2** · **F39**）
- [x] **S2**：自由输入「保存」成功后，标签名写入标签库（已存在则跳过）
- [x] **F9**：库标签数 > 10 时主区只显示已选库标签 +「选择标签」BottomSheet；≤10 全铺；面板内即时 `ToggleLibraryTag`

## 3. 用户操作

1. 点标签库 Chip：已有则移除，没有则加入并保存
2. 库标签 > 10：主区点已选 Chip 可取消；点「选择标签」在面板勾选/取消（即时保存）
3. 非库内自定义标签：Chip 编辑 / 关闭删除；下方输入框新增或改名（保存成功后自动入库）
4. 「套用模板」选模板 → **覆盖**为该模板标签集后保存（先 A 再 B = B）
5. 重命名模板在 [重命名.md](重命名.md) 区域，本区域不涉及

## 4. UI 描述

- 标题「标签」
- FlowRow：标签库 `FilterChip`（≤10 全库；>10 仅已选）
- 库 > 10 时：「选择标签」→ `ModalBottomSheet` 平铺全库 Chip
- FlowRow：不在库内的自定义 `InputChip`（编辑 / 删除）
- 「套用模板」按钮 + 菜单（无模板时禁用或提示）
- 输入框 + 保存 / 取消

## 5. 数据 / 事件

- `ToggleLibraryTag` / `ApplyTemplate` / `SaveTag` / `DeleteTag` → `repository.updateTags` + `ImageTagMetadata`
- `SaveTag` 成功后 → `TagRepository.insertTag`（已存在跳过）
- `TagRepository.observeTags` / `observeTemplates`
- F9 阈值常量：`LIBRARY_TAG_COLLAPSE_THRESHOLD = 10`（`ImageDetailScreen`）
