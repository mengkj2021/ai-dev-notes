# 图片详细画面 · 主图缩放

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片详细画面 |
| 区域名称 | 主图缩放 |
| 对应 UI | Coil `AsyncImage` + `detectTransformGestures` / 双击 |

## 2. 功能清单

- [x] 按 `filePath` 加载私有目录图
- [x] 双指 pinch 缩放（约 1x～5x）与平移
- [x] 双击重置缩放（恢复 1x、居中）
- [x] **F4 / S8**：scale>1 时隐藏重命名/标签区；回 1x 时恢复显示；**不支持**单击主图强制显示/再隐藏

## 3. 用户操作

1. 捏合放大/缩小；切换缩略条图片时重置缩放
2. 双击主图恢复 1x（并居中）
3. 放大时编辑区自动隐藏；回 1x（含双击）后编辑区自动显示

## 4. UI 描述

- 占主体主要高度（**Bug15**：纵向最低 **200.dp**；编辑区少时 `weight(1f)` 仍可占满剩余）；`ContentScale.Fit`；缩略条始终保留
- 下方编辑区超高时不继续压扁本区（见画面 README §5）

## 5. 数据 / 事件

- `ImageDetailViewModel.absoluteFile(item)`
