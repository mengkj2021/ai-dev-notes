# 图片详细画面 · 重命名

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片详细画面 |
| 区域名称 | 重命名 |
| 对应 UI | 文件名 `OutlinedTextField` + 确认按钮 |

## 2. 功能清单

- [x] 同目录改物理文件名 + 更新 DB（`fileName` / `filePath` / `description`）
- [x] 校验空名、非法字符、同目录重名；未写扩展名时保留原扩展名
- [x] 套用重命名模板（`{name}` `{date}` `{yyyy}` `{mm}` `{dd}` `{time}` `{tag}` `{tags}` `{n}`，保留扩展名；**F34/F45**：`{date}` 拍摄日优先，无则导入日；单张 `{n}`=1）
- [x] **F2**：输入框仅编辑主名；扩展名只读展示，不可改后缀
- [x] **F2**：主名全删后失焦，恢复进入编辑前的原主名

## 3. 用户操作

1. 编辑主文件名 → 「重命名」保存；失败 Snackbar
2. 「套用重命名模板」选择模板后立即重命名（扩展名仍锁定）

## 4. UI 描述

- 「文件名」标题 + 主名输入（suffix 显示 `.扩展名`）+ 按钮
- 「套用重命名模板」下拉（无模板时禁用）

## 5. 数据 / 事件

- `RenameDraftChanged` / `RenameFocusLost` / `SaveRename` → `repository.rename`
- `ApplyRenameTemplate` → `RenamePatternApplier` + 锁定扩展名后 `rename`

## 6. 待定事项
