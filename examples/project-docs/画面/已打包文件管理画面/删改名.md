# 删改名

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 已打包文件管理画面 / `export-manage` |
| 区域名称 | 删改名 |
| 对应 UI | 列表行「重命名」「删除」+ 确认 / 改名对话框 |

## 2. 功能清单

- [x] **F46**：删除 `exports/` 内 zip（确认后删；删后列表刷新）
- [x] **F46**：事后重命名主文件名；扩展名固定 `.zip`
- [x] 合法 stem：复用 F42 `ExportZipNames`（空、非法字符拦截）
- [x] 与同目录已有文件冲突：**Snackbar 拒绝**，不自动 `_2`（异于打包落盘）
- [x] 仅改 stem 与当前相同 → 关闭对话框，不提示失败

## 3. 用户操作

1. 点「删除」→ 确认对话框 → 确认后删除文件并刷新
2. 点「重命名」→ 对话框预填当前 stem → 改名确认
3. 非法名 / 冲突 → Snackbar，对话框可继续改

## 4. UI 描述

- 列表行 trailing：`分享` / `重命名` / `删除`（TextButton）
- 删除：`AlertDialog` 确认
- 改名：`AlertDialog` + `OutlinedTextField`（suffix `.zip`）

## 5. 数据 / 事件

- 读：列表项 `absolutePath` / `fileName`
- 写：`ExportManageUiEvent.RequestDelete` / `ConfirmDelete` / `RequestRename` / `ConfirmRename` 等
- 规则：`ExportZipNames.planZipRename`（先测后写）
