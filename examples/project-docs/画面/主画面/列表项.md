# 列表项（主画面共用）

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 主画面（`main`） |
| 区域名称 | 列表项 |
| 对应 UI | `ImageListItemRow` |

## 2. 功能清单

- [x] 72dp Coil 缩略图（失败回退占位色）
- [x] 日期（次要色小字）+ 描述（单行省略）+ 标签 AssistChip
- [x] 编辑模式：左侧 Checkbox
- [x] 非编辑模式：整行点击 → `image-detail/{imageId}`

## 3. 用户操作

1. 非编辑：点击行进入详情
2. 编辑：点击行或 Checkbox 切换选中

## 4. UI 描述

- 单行 `Row`：可选 Checkbox | 缩略图 | 文本列（日期 / 描述 / FlowRow 标签）

## 5. 数据 / 事件

- 数据：`ImageListItem`（含 `filePath`）
- 事件：`ToggleSelect(id)`；导航由 `MainScreen` `onNavigateToDetail` 处理

## 6. 待定事项

- 无
