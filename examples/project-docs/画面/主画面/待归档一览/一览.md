# 待归档一览 · 一览

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 主画面 · 待归档 Tab |
| 区域名称 | 一览 |
| 对应 UI | `ImageListTab` + `LazyColumn` + 底部分页条；空态 `EmptyListPlaceholder` |

## 2. 功能清单

- [x] Room Flow 展示 `ImageStatus.Pending`；经标签筛选后分页（**F15**：默认每页 30，设置可配；关分页则展示当前筛选全部、隐藏页码栏）
- [x] 编辑模式勾选；空列表提示
- [x] 底部分页：上一页 / 下一页 /「第 x / y 页」（仅分页开启时显示）
- [x] 列表项见 [列表项.md](../列表项.md)

## 3. 用户操作

1. 浏览当前页待归档图片；翻页切换（关分页时无翻页）
2. 非编辑点击进详情；编辑勾选后配合菜单「移动到」

## 4. UI 描述

- `LazyColumn`（当前页；关分页为全部筛选结果）；空时居中文案（`empty_pending`）
- 底栏（分页开）：上一页（首页禁用）/ 文案 / 下一页（末页禁用）

## 5. 数据 / 事件

- `observeItems(Pending)` → ViewModel 标签过滤 + `ListPaging` 切片；目录 `images/pending/`
- `PrevPage` / `NextPage`（关分页无操作）

## 6. 待定事项

- 无
