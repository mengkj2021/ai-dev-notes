# 待归档一览 · 菜单

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 主画面 · 待归档 Tab |
| 区域名称 | 菜单 |
| 对应 UI | `TabActionBar` + 筛选条件摘要（`MainTab.Pending`） |

## 2. 功能清单

- [x] 编辑 / 完成
- [x] 「移动到」→ 已归档 / 回收站（编辑且有选中时，行内）
- [x] **F14**：「重命名」→ 套用重命名模板（编辑且有选中时，行内「移动到」旁；无模板时禁用）
- [x] 「导入图片」→ `import-images`（右侧）
- [x] **筛选**：跳转 [`filter`](../../筛选画面/README.md)；返回后展示条件摘要 Chip；可清除
- [x] **F5**：「更多」溢出菜单含全选（仅编辑态）；删除在回收站 Tab

## 3. 用户操作

1. 点「编辑」进入编辑模式；「完成」退出并清空选中
2. 「更多」→「全选」勾选**当前页**列表项（**F15** 关分页时 = 当前筛选全部）
3. 「移动到」选择目标状态，批量改库 + 搬文件
4. 「重命名」选模板 → 对选中项逐张套模板改名；失败项弹明细（可单张 / 全部重试）
5. 「导入图片」进入导入画面
6. 「筛选」→ `filter`；应用后该 Tab 回到第 1 页并清空选中；摘要 Chip /「清除」展示当前条件

## 4. UI 描述

- 水平工具栏：编辑、（编辑态）移动到、重命名、筛选、更多；导入在右侧
- **Bug8**：编辑态增控件时行高与 IconButton 默认触控高度对齐，避免行「跳高」
- 有筛选时：工具栏下方 Chip 摘要（标签 / 未打标签 / 文件名关键字）+ 清除
- 批量重命名失败：AlertDialog 明细（文件名 + 原因），单张 / 全部重试（仿导入 P1）
