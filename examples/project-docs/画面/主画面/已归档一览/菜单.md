# 已归档一览 · 菜单

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 主画面 · 已归档 Tab |
| 区域名称 | 菜单 |
| 对应 UI | `TabActionBar` + 筛选条件摘要（`MainTab.Confirmed`） |

## 2. 功能清单

- [x] 编辑 / 完成
- [x] 「移动到」→ 待归档 / 回收站（编辑态行内）
- [x] **F14**：「重命名」→ 套用重命名模板（编辑且有选中时，行内；同待归档）
- [x] **打包导出** → `export-zip`（C7）
- [x] **筛选**：跳转 [`filter`](../../筛选画面/README.md)；返回展示摘要；可清除
- [x] **F5**：全选收入「更多」溢出菜单

## 3. 用户操作

1. 编辑 →「更多」全选当前页（**F15** 关分页时 = 当前筛选全部）→「移动到」改状态
2. 「重命名」套模板批量改名（失败明细同待归档）
3. 「完成」退出编辑
4. 「筛选」同待归档一览 · 菜单
5. 「打包导出」进入打包画面

## 4. UI 描述

- 工具栏：编辑、（编辑态）移动到、重命名、筛选、更多；右侧「打包导出」

## 5. 数据 / 事件

- `ToggleEditMode` / `SelectAll` / `MoveSelectedTo` / `ApplyRenameTemplate` / `SetTagFilter` / `ClearTagFilter`
- `RetryRenameFailure` / `RetryAllRenameFailures` / `DismissRenameFailures`
- 导航：`export-zip`
