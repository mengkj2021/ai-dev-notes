# 已归档一览 · 一览

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 主画面 · 已归档 Tab |
| 区域名称 | 一览 |
| 对应 UI | `LazyColumn` + 列表项 + 底部分页条 |

## 2. 功能清单

- [x] 展示 `ImageStatus.Confirmed`；标签筛选后分页（**F15**：同待归档一览，设置可配）
- [x] 编辑勾选；空态提示
- [x] 底部分页：上一页 / 下一页 /「第 x / y 页」（仅分页开启时显示）
- [x] 列表项见 [列表项.md](../列表项.md)

## 3. 用户操作

1. 浏览当前页已归档图片；翻页（关分页无翻页）；点击进详情或编辑后移动

## 4. UI 描述

- 同待归档一览结构；空文案 `empty_confirmed`

## 5. 数据 / 事件

- `observeItems(Confirmed)` → ViewModel 过滤 + `ListPaging`；目录 `images/confirmed/`
- `PrevPage` / `NextPage`

## 6. 待定事项

- 无
