# 回收站一览 · 菜单

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 主画面 · 回收站 Tab |
| 区域名称 | 菜单 |
| 对应 UI | `TabActionBar` + 筛选条件摘要（`MainTab.NoModify`） |

## 2. 功能清单

- [x] 编辑 / 完成
- [x] 「移动到」→ 待归档 / 已归档（编辑态行内）
- [x] **F14**：「重命名」→ 套用重命名模板（编辑且有选中时，行内；同待归档）
- [x] **F5**：「更多」内全选 / 删除（删私有文件 + DB；需编辑且有选中）
- [x] 「筛选」：跳转 [`filter`](../../筛选画面/README.md)；返回展示摘要；可清除；回传落**进入时 Tab**（Bug6）
- [x] **F33**：右侧「清空」→ 确认弹窗后删除**回收站内全部**图片（文件 + DB；不受当前页 / 筛选限制）；空列表时禁用

## 3. 用户操作

1. 编辑 →「更多」全选（**F15** 关分页时 = 当前筛选全部）或删除
2. 或「移动到」改状态并搬文件
3. 「重命名」套模板批量改名（失败明细同待归档）
4. 「筛选」同待归档一览 · 菜单
5. 「清空」→ 确认 → 删除回收站全部项（非仅当前页 / 当前筛选）

## 4. UI 描述

- 编辑态：移动到、重命名；筛选 icon + 更多（含删除）；有条件时 Chip 摘要
- 右侧常显「清空」（对位待归档「导入」、已归档「导出」）；无回收站项时禁用；点后 `AlertDialog` 二次确认

## 5. 数据 / 事件

- `DeleteSelected`（仅本 Tab）；`EmptyTrash`（确认后）；`MoveSelectedTo` / `ApplyRenameTemplate`
- `RetryRenameFailure` / `RetryAllRenameFailures` / `DismissRenameFailures`
- `SetTagFilter` / `ClearTagFilter`
