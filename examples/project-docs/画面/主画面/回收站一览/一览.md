## 2. 功能清单

- [x] 展示 `ImageStatus.NoModify`；标签筛选后分页（**F15**：同待归档一览，设置可配）
- [x] 编辑勾选；空态
- [x] 底部分页：上一页 / 下一页 /「第 x / y 页」（仅分页开启时显示）
- [x] 列表项见 [列表项.md](../列表项.md)

## 3. 用户操作

1. 浏览当前页；翻页（关分页无翻页）；详情或配合菜单删除 / 移动

## 4. UI 描述

- `observeItems(NoModify)` → ViewModel 过滤 + `ListPaging`；目录 `images/no_modify/`
- `PrevPage` / `NextPage`
