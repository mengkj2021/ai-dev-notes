# 标签管理 · 标签模板

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 标签管理（`tag-manage`） |
| 区域名称 | 标签模板 |
| 对应 UI | Tab「模板」+ 列表 / 编辑对话框 |

## 2. 功能清单

- [x] 展示模板名、包含的标签 Chip、是否默认
- [x] 添加 / 编辑：名称 + 多选库内标签；**F35**：失败 Dialog 内联；成功 Snackbar 即时替换
- [x] **Bug11**：名称 trim 后与其它模板重名 → Dialog 内联「模板名已存在」，不关窗、不落库；编辑保留自身原名可保存
- [x] 设为默认（唯一）
- [x] 删除（确认）

## 3. 用户操作

1. 添加模板并勾选标签 → 保存
2. 设默认 / 编辑 / 删除

## 4. UI 描述

- 列表行；编辑用对话框或底部表单（名称 TextField + FilterChip 多选）
- **Bug9**：列表 `contentPadding` 底边预留 FAB 净空，滚到底末项仍可读可点

## 5. 数据 / 事件

- `observeTemplates` / `insertTemplate` / `updateTemplate` / `deleteTemplate` / `setDefaultTemplate`
- 保存前：`classifyTemplateNameSaveFailure`（空名 / 重名）；库层 `require` 二次拦截（Bug11）

## 6. 待定事项

- 无
