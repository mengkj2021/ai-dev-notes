# 标签管理 · 标签列表

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 标签管理（`tag-manage`） |
| 区域名称 | 标签列表 |
| 对应 UI | Tab「标签」+ LazyColumn |

## 2. 功能清单

- [x] 观察并展示全部标签（排序）
- [x] 添加（对话框输入名）；**F35**：失败原因 Dialog 内联；成功 Snackbar（即时替换）；**F34**：空名 / 重名 / 状态保留字分文案
- [x] 编辑名称
- [x] 删除（确认）；**F8**：无引用直接删；有引用二次确认后清图片 `tagsJson` + Exif
- [x] 编辑改名；**F48**：无图片引用直接改词表 + 默认标签集合；有引用二次确认后同步图片 `tagsJson` + Exif + 默认标签

## 3. 用户操作

1. 点添加 → 输入 → 保存
2. 点行编辑或删除（改名 / 删标签有图片引用时二次确认影响张数）

## 4. UI 描述

- FAB 或顶栏添加；行：名称 + 编辑/删除图标
- **Bug9**：列表 `contentPadding` 底边预留 FAB 净空，滚到底末项仍可读可点

## 5. 数据 / 事件

- `observeTags` / `insertTag` / `updateTag` / `deleteTag`
- F8：`ImageRepository.countImagesWithTag` / `removeTagFromAllImages`
- F48：`ImageRepository.renameTagInAllImages`；`UserPreferencesRepository.renameDefaultTagName`
