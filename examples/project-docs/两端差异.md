# 两端差异（Android / Windows）

> 图片整理 **一份**规格在本目录其它文件。本文只索引两端会分叉的点。  
> Android 代码：[`examples/android/`](../android/)。Windows：[`examples/windows/`](../windows/)（阶段① 推进中）。

## 约定

- 其它 `project-docs` 正文默认写**产品意图**（两端共用）
- 已落地实现写「Android：路径…」或「Windows：路径…」
- 尚未对齐处写「Windows：阶段2」或具体缺口

## 差异索引

| 主题 | Android（已落地） | Windows |
|---|---|---|
| 工程 | Gradle；Open `examples/android/` | Gradle；Open `examples/windows/`（`:composeApp`） |
| UI | 单 Activity + Jetpack Compose | Compose Desktop：侧栏 NavigationRail + 菜单栏（非手机底栏） |
| 导航 | Navigation Compose / `Routes.kt` | 自管导航 + 同名 `Routes`；Esc 返回；Ctrl+I/E/,/A |
| 存储 | 应用私有目录 `filesDir/images`、`exports/` | `%LOCALAPPDATA%/PictureOrganizer/images`、`exports/`（子目录名同 Android） |
| 元数据 | Room v5 | JSON 原子写：`images.json` + `catalog.json`（可换 SQL） |
| 偏好 | DataStore | `prefs.json`（默认标签/压缩/重名询问；**分页默认关**） |
| 权限 / 相册 | 系统相册与 SAF 导入；无网络权限 | JFileChooser + 拖放导入；无网络 |
| 打包 | 单个 zip + FileProvider 分享 | zip → `exports/` 或另存为；资源管理器定位（无系统分享） |
| 发版 | `examples/android/scripts/…` | `nativeDistributions`（Msi/Exe）可用；图标/uuid 待打磨 |
| 画面技能 | `create-screen-doc` / `implement-screen` | 不要套用 Compose 技能 |
| 国际化 | 简中/日/英系统跟随 | 仍简中硬编码 |
| Exif | `ExifInterface` 标签/拍摄日 | 读：metadata-extractor；写：commons-imaging（JPEG）；压缩后补写 |

进度：Android → [android 车道](../project-status/android/)；Windows → [windows 车道](../project-status/windows/)。
