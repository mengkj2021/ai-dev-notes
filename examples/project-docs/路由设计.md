# 路由设计

> **Android 现状**：`examples/android/.../navigation/`（`Routes.kt`、NavHost）。Windows：未实现。画面规格见 [`画面/`](画面/)。

## 1. 约定

- 单 Activity；Navigation Compose；route 字符串常量集中在 `Routes.kt`

## 2. route 命名约定

| 规则 | 示例 |
|---|---|
| 全小写，多词用连字符 | `import-images` |
| 传参用路径参数，`{}` 包裹 | `detail/{imageId}` |
| 根画面固定为 `splash` | `splash` |

## 4. 新增画面

按 [画面/README.md](画面/README.md)「新增画面」：复制模板 → 登记本表 §3 一行 → 更新画面清单 → 再实现代码。

## 5. 系统返回动作

| 层级 | 默认行为 |
|---|---|
| 非根画面 | 返回键 / 顶栏返回 = 上一画面。**安全 pop**：仅当前仍是目标 route 且 pop 后栈非空才执行（Bug6 / Bug10）。transition 未 RESUMED 时勿 pop；顶栏 Icon 用 `BackNavIconButton`；Text/主按钮出口用 `ResumedTextButton` / `ResumedButton`（Bug17）；NavHost 可再 `dropUnlessResumed` 兜底 |
| 根画面（main） | 返回键 = 退出应用；**禁止**被误 pop 成 NavHost 空窗 |
| splash | 按教程完成状态 → `tutorial` 或 `main`，均不在 back stack 保留 |
| tutorial（首次） | 完成/跳过写入 `tutorial_completed` 后进 `main`，不回 splash |
| tutorial（`fromSettings=true`） | 结束仅 `pop` 回设置，不改写完成标记 |
| 带编辑 / 未保存 | `BackHandler` 拦截并确认，由各画面文档约定 |
| 导入中 | `BackHandler` 始终启用并吞掉返回（F10）；勿 `enabled=false` 把事件交回 Navigation |

过程见相关票复盘与 git；不另建开发日志。
