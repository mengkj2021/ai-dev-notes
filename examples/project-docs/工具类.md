# 工具类

> **Android 现状**：跨画面无 UI 工具与少量共享模型。Windows：未实现。对应 `util/`、`ui/common/`、`model/`。

## `util/`

| 类 | 包 | 职责 |
|---|---|---|
| `AppFileManager` | `util/file/` | 三子目录、URI 复制、跨状态搬移、同目录重命名、删除、`exportsDir`、清 pending 孤儿 |
| `BatchRenamePlanner` | `util/file/` | 一览批量套模板规划（冲突检测；纯 JVM） |
| `PendingOrphanCleaner` | `util/file/` | 判定 `pending/` 无 DB 记录的孤儿名（纯 JVM） |
| `RenamePatternApplier` | `util/file/` | 模板 → 文件名。顺序固定：先 `{name}`/`{tags}`，再 `{n}`/`{tag}`，否则互相吞字 |
| `ZipExporter` | `util/file/` | 文件列表 → **一个** zip → `exports/`（S7；内容由上层 `ExportZipPack` 决定） |
| `ExportZipNames` | `util/file/` | F42/S7：默认 stem、非法名、冲突最终名；F46：`planZipRename`（事后改名冲突拒绝） |
| `ImageManager` | `util/image/` | `prepareForImport`：按开关压缩或原样写入 `pending/`。阈值常量 `MAX_BYTES`/`MAX_LONG_EDGE`/`JPEG_QUALITY`＝**现行临时**（2MB / 1920 / 85），是否定稿见 [阶段4 · 待对应](../project-status/android/阶段/阶段4-维护与迭代/待对应.md) |
| `ImageTagMetadata` | `util/image/` | 用户标签 ↔ Exif `UserComment` JSON（纯 Kotlin 编解码，ASCII 安全 `\uXXXX`）。读：`getAttributeBytes` + charset 前缀剥离（ASCII/UNICODE/JIS）；写：`writeUserTags` / 导入后 `writeImportMetadata`（含拍摄日）。失败 / 非本应用 JSON → 空列表 |
| `ExifDateTaken` | `util/image/` | Exif `DateTimeOriginal` ↔ millis（`parseToMillis` / `formatToExif` / `formatForDisplay`）。无时区按设备默认区；blank / 错格式 → `null` |
| `ImportDuplicateLogic` | `util/image/` | 原图名规范化与批内/库内判重。`trim` + 忽略大小写；空串永不冲突 |
| `ListPaging` | `util/list/` | 一览切片 |
| `AppLog` | `util/log/` | F47：仅 `BuildConfig.DEBUG`；tag 前缀 `PO/` |

## `ui/common/`

## `model/`（纯逻辑为宜）

| 类 | 职责 |
|---|---|
