# 核心流程

> **android 现状**：主路径摘要。细则以各 [画面/](画面/) 与代码为准。

**导入 → 分类 → 标签 / 重命名 → 筛选后将已归档图打成单个 zip 导出**

## 导入

- 复制进私有目录（非移动）；来源：相册 / 图库，或文件选择器
- 可选压缩（默认开）：现行阈值 **> 2MB** 或长边 **> 1920px** → JPEG≈85，否则原样。  
  > **临时未正式定稿**——是否改参数见 [阶段4 · 待对应](../project-status/android/阶段/阶段4-维护与迭代/待对应.md)；勿当产品终局规格。
- 可合并默认标签；可从 Exif 回读本应用用户标签与拍摄日期

## 分类

- 三 Tab：**待归档 / 已归档 / 回收站**（目录见 [图片存储管理.md](图片存储管理.md)）
- 「移动到」改状态并搬文件；**状态不算标签**（`tagsJson` / Exif 仅用户标签）
- 状态保留字：简中键「待归档 / 已归档 / 回收站」+ 旧键「待处理 / 已确认」从历史剥离；日/英等显示名别名仅拦**新建**标签

## 标签 / 重命名

- 详情：重命名（可套模板）、加标签（库选 / 模板 / 自由输入；成功则入库）
- 一览编辑态可批量套重命名模板
- 用户标签：Room 为真源，并双写 JPEG Exif
- **F48**：标签库改名且有引用 → 二次确认后原位替换各图 `tagsJson` / Exif，并同步默认标签集合

## 筛选与导出

- 筛选（一览与打包共用）：文件名包含、排序（导入日 / 文件名 / 拍摄日）、拍摄日区间、导入日区间
- 已归档 → 打包（**S7**）：命中图打成 **一个** zip → `filesDir/exports/`，FileProvider 分享
- **F41**：打包前预览可单张排除（会话临时）
- **F42 / S7**：可改该 zip 主文件名（默认 `export_{日期}.zip`；非法名提示；与已有 exports 冲突自动 `_2`）
- **F43 / F46**：历史 zip 列表 / 再分享 / 删除 / 事后改名（冲突拒绝，不自动 `_2`）
