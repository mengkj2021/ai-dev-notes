# 项目概述

> **共享规格**：产品定位与形态。未决见对应车道 [`project-status/`](../project-status/README.md)。两端差：[两端差异.md](两端差异.md)。

## 1. 定位

- 本地 **图片管理**（Android 已落地；Windows 阶段① 主路径可跑）。
- 场景：按规则归类后，**直接操作私有目录中的真实文件**（复制导入、状态间移动、重命名、筛选后打成**单个** zip 导出）。
- Android 工程：[`examples/android/`](../android/)（Gradle root）。Windows：[`examples/windows/`](../windows/)（Compose Desktop）。

## 2. 应用形态

- 单 Activity + Jetpack Compose（**Android**）；单窗口 Compose Multiplatform Desktop（**Windows**）。差异见 [两端差异.md](两端差异.md)。
- 全程本地、**不联网**（Manifest 无网络权限；不参与云备份 / 设备间迁移，见 [图片存储管理.md](图片存储管理.md)）。

## 3. 源码注释约定

- `examples/android/` **默认无注释**（含票号）；约束与坑写在 `project-docs/` 或票库。
- `@Suppress` 等编译注解保留；产品级说明以本文档为准。
