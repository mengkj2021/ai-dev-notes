# 架构设计

「图片整理」**当前 Android** 技术架构（对照 [`examples/android/`](../android/)）。**包结构以本节 §2 为准。** 全程本地、不联网。Windows 未实现，见 [两端差异.md](两端差异.md)。

> 对应：`examples/android/app/src/main/java/com/pictureorganizer/`（改布局先改 §2 再改代码）。

## 1. 总览

| 层级 | 选型 |
|------|------|
| 界面 | 单 Activity + Jetpack Compose + Material 3 |
| 导航 | Navigation Compose（`splash` → `tutorial`/`main`；另含 import / detail / settings / filter / export-zip / export-manage 等） |
| 状态 | MVVM（`*UiState` / `*UiEvent` / `*UiEffect`） |
| 数据 | Repository；Room **v5**（`images`+`tags`+`tag_templates`+`rename_templates`；含 `originalName`、`dateTakenMillis`） |
| 偏好 | DataStore：教程完成、默认标签、导入压缩、重名询问、列表分页开关、每页数量 |
| 文件 / 图片 / 导出 | 见 [工具类.md](工具类.md)（`AppFileManager`、`ImageManager`、`ZipExporter` 等） |
| 图片加载 | Coil（列表缩略图 + 详情主图） |
| 分享 | `FileProvider`（`exports/`） |

## 2. 包结构

根包：`examples/android/app/src/main/java/com/pictureorganizer/`。

### 2.1 目录树

```
com.pictureorganizer/
├── PictureOrganizerApplication.kt
├── MainActivity.kt
├── navigation/                 # Routes、NavHost、FilterResultKeys
├── model/
│   ├── ImageListItem.kt / ImageStatus.kt  （STATUS_TAGS：待归档/已归档/回收站；旧键仍剥离；UI 经 strings）
│   ├── ImageTagFilter.kt                 （标签筛选；主画面 / 打包共用）
│   ├── ExportZipPack.kt                  （F41 / S7：排除 id + 单包导出）
│   ├── Tag.kt / TagTemplate.kt / RenameTemplate.kt
│   ├── TagFilterCriteria.kt
│   ├── TagNameSaveFailure.kt
│   └── TagTemplateApply.kt
├── data/
│   ├── repository/             # Image / Tag / RenameTemplate / UserPreferences；Room* 实现（无 Mock）
│   ├── mapper/                 # ImageMappers、TagMappers（含 RenameTemplate）
│   └── local/                  # Entity、DAO、Migration1–5、AppDatabase、converter/
├── util/
│   ├── file/                   # AppFileManager、BatchRenamePlanner、ZipExporter、ExportZipNames、RenamePatternApplier、PendingOrphanCleaner
│   ├── image/                  # ImageManager、ImageTagMetadata、ExifDateTaken、ImportDuplicateLogic
│   ├── list/                   # ListPaging
│   └── log/                    # AppLog（F47：仅 DEBUG）
└── ui/
    ├── splash/ / tutorial/
    ├── main/                   # MainScreen、ViewModel、MainTab…
    │   └── tab/                # ImageListTab、TabActionBar、ListPageBar、行/空态等
    ├── filter/
    ├── importimages/ / imagedetail/
    ├── settings/ / tagmanage/
    ├── renametemplate/         # 管理/编辑；含 PatternTokenInsert
    ├── defaulttags/
    ├── exportzip/ / exportmanage/
    ├── osslicenses/
    ├── common/                 # BackNavIconButton、SnackbarHostStateExt、LogScreenLifecycle、FabOverlayListContentPadding
    └── theme/
```

### 2.2 放置约定

| 内容 | 位置 |
|---|---|
| 画面 Composable | `ui/<screen>/`（纯 UI） |
| 画面逻辑 | 同包 `*ViewModel` + `*UiState` / `*UiEvent` / `*UiEffect` |
| 跨画面 UI 小工具 | `ui/common/` |
| 领域 / UI 模型 | `model/`（无 Android 框架依赖为佳） |
| 数据访问 | `data/repository/` |
| Room | `data/local/` |
| Entity ↔ UI | `data/mapper/` |
| 无 UI 工具 | `util/`（含 `util/log/AppLog`） |
| route 常量 | `navigation/Routes.kt` |
