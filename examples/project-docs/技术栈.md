> **Android 现状**：以 `examples/android/gradle/libs.versions.toml` 与 `examples/android/app/build.gradle.kts` 为准。Windows：未实现。

## 多语言

简中（默认）/ 日 / 英；**仅跟随系统**，无应用内开关；缺译回退简中。UI 三语对齐；用户数据（标签名、文件名等）不翻译。状态键库内为简中「待归档 / 已归档 / 回收站」（S5；旧键仍剥离）；UI 显示名随语言。工程文档与票库保持中文。
