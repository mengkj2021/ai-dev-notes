- 要解决的问题：图库没有「拍摄时间」字段；`{date}` / 排序目前只能用导入日期

- 是否已有式样依据：否（F13 起票；本票落地数据与详情展示）

## 需求确认（已锁定，源自 F13）

- **字段**：`ImageEntity.dateTakenMillis: Long?`；`ImageListItem` 同步；旧行 null
- **迁移**：**Room v4 → v5** + `MIGRATION_4_5`（F11 已占用 v4 / `originalName`，勿再写 v3→v4）
- **读取时机**：导入**压缩前**从来源读 Exif `DateTimeOriginal`；无标签或失败 → null
- **展示**：详情可看拍摄日期（`yyyy-MM-dd HH:mm`）；列表不加列（防拥挤）；导入成功明细展示范围本票可不做
- **不纳入本票**：筛选排序/区间（→ F25）；`{date}` 语义（→ F17）
