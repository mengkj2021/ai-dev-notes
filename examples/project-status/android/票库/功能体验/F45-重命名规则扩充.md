## 已锁定（占位符总清单）

| 占位符 | 含义 |
|---|---|
| `{name}` | 当前文件名去扩展名（保留） |
| `{date}` | `yyyyMMdd`；拍摄日优先，无则导入日（F26/F34，保留） |
| `{tag}` | 首个用户标签；无则空串（保留） |
| `{yyyy}` `{mm}` `{dd}` | 与 `{date}` **同一日期来源**的年 / 月 / 日（`mm`/`dd` 两位补零） |
| `{time}` | `HHmmss`；优先 `dateTakenMillis` 的时分秒，无则用 `importedAt` |
| `{tags}` | 全部用户标签，以 `_` 连接；无则空串 |
| `{n}` | 本批序号，从 **1** 起（单张套用视为 `1`）；十进制、不强制补零 |

**不做**（本票）：宽高、状态名、原扩展名占位（扩展名仍由 Applier 拼回）、依赖新库字段的规则。
