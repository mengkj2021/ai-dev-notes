## 用户诉求 / 场景

- 要解决的问题：`ImageListItem.STATUS_TAGS`（「待处理」「已确认」「回收站」）既是数据层保留字又是历史显示名；日/英 UI 下若直接展示中文键不友好，若改库内值会破坏筛选 / Exif / S1
- 预期效果：库内与 Exif / 筛选仍用中文保留字；界面显示名按当前语言映射
- 是否已有式样依据：S1（状态不算标签）、S3（回收站命名）；本票补「键 vs 显示」文档

## 需求确认（已锁定，源自 F23）

- 库内键：**保持中文**（「待处理」「已确认」「回收站」）
- UI：经资源或映射表显示本地化名
- 不改用户自定义标签语义；不把状态当标签（S1）
