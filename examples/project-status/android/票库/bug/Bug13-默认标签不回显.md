## 现象（用户可观察）

1. 复现步骤：设置 → 默认标签 → 勾选若干库标签 → 点保存返回 → 再次进入默认标签
2. 实际结果：看不到当前已保存的默认集合（表现为空选或无法辨认上次勾选）
3. 期望结果：再次进入时 Checkbox **回显** DataStore 中已保存的勾选（不是空选）

## 影响范围

- 涉及画面 / route：`default-tags`

## 根因（调查后填）

- **根因**：`collectAsStateWithLifecycle(emptySet())` 占位触发 `LaunchedEffect`，`selected == null` 仅首次生效，被锁死在初始空集，DataStore 真实值到达后不再同步。
- 定位证据：`DefaultTagsScreen.kt` 草稿同步逻辑
