## 现象（用户可观察）

1. 复现步骤：
   1. 主画面（待归档一览）冷启动或稳定态：点顶栏标题「图片整理」→ **无动作**（可接受）
   2. 点「导入图片」进入导入画面，再返回主画面
   3. 再点顶栏标题「图片整理」→ **进入白屏**
   4. 用户反馈：已归档 / 回收站一览有**类似**问题（接票时三 Tab × 常见子画面往返一并点验）
2. 实际结果：子画面往返后，点顶栏标题会白屏（疑似 NavHost 空窗）
3. 期望结果：
   - 顶栏标题「图片整理」**始终无导航动作**（与式样：仅设置齿轮进设置）
   - 任意子画面返回后，主画面内容区仍为列表 / 空态，不白屏
   - 修法覆盖三 Tab；接票时全面检查同类往返，整理根因并写入错题本，避免再犯

## 影响范围

- 涉及画面 / route：`main`（三 Tab）；子画面离开路径（Import / Settings / Filter / Detail 等）
- 涉及数据或文件：无（导航栈，非 Room）

## 根因（调查后填）

- **根因链（同 Bug6 族）**：子画面离开时连点 / 叠返回导致二次 `popBackStack`，把根 `main` 弹出 → NavHost 空窗白屏。标题本身无 `onClick`；表面「点标题白屏」是往返后栈已脆 / 二次 pop 的表现，非标题导航。
- **为何仅 filter 修过仍复发**：Bug6 只收口 `popFilterIfOnTop`；Import 等仍裸 `popBackStack`，无空栈守卫。
- 定位证据：代码对照 Bug6 + `compileDebugKotlin` 通过；真机 F47 `PO/Nav` 栈摘要待点验补记。

## 已锁定（接票时确认；绿档可写「见现象/期望」或省略本节）

- 顶栏「图片整理」**永不导航**（与式样一致；标题无 `onClick` 须保持）
- 任意子画面返回后，主画面不得被 pop 出栈 → 禁止 NavHost 空窗白屏
- 修法覆盖三 Tab；至少点验：导入 / 设置 / 筛选（Bug6 回归）往返后再点标题
- 先测后写：**否**（纯导航 / UI，无 JVM 纯逻辑可抽）
