## 变更内容（已确认的式样）

- 现状：主画面三 Tab「待处理 / 已确认 / **不修改**」；`ImageStatus.NoModify`、目录 `no_modify/`、枚举内部命名
- 变更为：**显示层改名「回收站」**——NavigationBar Tab、空态文案、工具栏「移动到 → 回收站」、教程引导文案、保留字提示文案等用户可见「不修改」字样全部换为「回收站」
- 变更理由：该 Tab 实际用途即存放「决定不再修改 / 不需要」的图片，可删除（真删）、可移出恢复（移到待处理 / 已确认），用户认知等同回收站，原名误导（"不修改"像未处理）
- **行为不变**：移动 / 删除 / 筛选语义、`ImageStatus` 枚举值、`status` 字段、目录名 `no_modify/`、DB 数据一律不动，仅换显示文案
- 是否涉及「待定」项澄清：是——保留字集合 `STATUS_TAGS` 更新为 `setOf("待处理", "已确认", "回收站")`；旧词「不修改」**不再保留**为禁用词（2026-09-03 接票确认）
