# 图片详细画面 · 主图缩放

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片详细画面 |
| 区域名称 | 主图缩放 |
| 对应 UI | Coil `AsyncImage` + `detectTransformGestures` / tap |

## 2. 功能清单

- [x] 按 `filePath` 加载私有目录图
- [x] 双指 pinch 缩放（约 1x～5x）与平移
- [x] 双击重置缩放（恢复 1x、居中）
- [x] **F4**：scale>1 时默认隐藏重命名/标签区；单击主图切换强制显示
- [x] **Bug5**：捏合/平移会取消强制显示；变换结束后短时忽略伪单击，避免「放大了编辑区又闪回」
- [x] 进入放大或回到 1x 时清「强制显示」；捏合/平移进行中也取消强制显示

## 3. 用户操作

1. 捏合放大/缩小；切换缩略条图片时重置缩放
2. 双击主图恢复 1x（并居中）
3. 放大后单击主图：显示/隐藏下方编辑区；若再捏合或平移，编辑区重新隐藏

## 4. UI 描述

- 占主体主要高度（**Bug15**：纵向最低 **200.dp**；编辑区少时 `weight(1f)` 仍可占满剩余）；`ContentScale.Fit`；缩略条始终保留
- 下方编辑区超高时不继续压扁本区（见画面 README §5）

## 5. 数据 / 事件

- `ImageDetailViewModel.absoluteFile(item)`

## 5.1 实现约束（Bug5）

- 捏合结束后抬指易被识别为单击：变换结束后约 **350ms** 内忽略 tap
- 缩放与 tap 分属两个 `pointerInput`：用可变引用读最新状态，避免闭包过期导致强制显示错乱
