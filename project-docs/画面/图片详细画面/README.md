# 图片详细画面

## 1. 画面概述

| 项 | 内容 |
|---|---|
| 画面名称 | 图片详细画面 |
| route | `image-detail/{imageId}` |
| 职责 | 单张浏览（缩放）、重命名、标签；底部同状态缩略条切换；**F30** TopAppBar「更多」移动到 /（回收站）删除 |

## 2. 路由定义

- 路由字符串：`image-detail/{imageId}`
- 必选参数：`imageId`
- 参数说明：读库得 `status`；缩略条仅同 status

## 3. 功能清单（总览）

- [x] 无底部 NavigationBar；TopAppBar 返回
- [x] **F32**：编辑区顶部只读展示拍摄日期（有 `dateTakenMillis` → `yyyy-MM-dd HH:mm`；否则「拍摄日期未知」）；列表不加列
- [x] **F52**：拍摄日期下一行只读展示文件体积（`File.length()` → `Formatter.formatShortFileSize`；缺失/不可读 →「图片大小未知」）；不入库、不做分辨率；列表不加列
- [x] **F34 / F45**：套用重命名模板时 `{date}` 拍摄日优先；占位符总清单见 [重命名.md](重命名.md)
- [x] **F30 / S9**：移动后仅同状态全量无剩余图时返回主画面一览（与缩略条一致；见 [状态操作.md](状态操作.md)）
- [x] 区域见下表

| 区域 | 文档 |
|---|---|
| 主图缩放 | [主图缩放.md](主图缩放.md) |
| 重命名 | [重命名.md](重命名.md) |
| 标签 | [标签.md](标签.md) |
| 缩略条 | [缩略条.md](缩略条.md) |
| 状态操作 | [状态操作.md](状态操作.md)（**F30**） |

## 4. 用户操作（总览）

1. 主列表非编辑点击进入
2. 缩放 / 重命名 / 改标签 / 缩略条切换
3. **F30**：「更多」移动到其他状态；回收站可删除（确认后回一览）
4. 返回主画面

## 5. UI 壳层

- 顶部：`TopAppBar`（标题=文件名）+ 返回 + **F30**「更多」
- 主体：主图 → 重命名/标签 → 缩略条
- **Bug15**：主图纵向最低 **200.dp**；编辑区（重命名/标签）高度上限 = 可用高度 − 主图最低 − 缩略条，超出则区内纵向滚动，不继续挤占主图；缩略条固定保留；编辑区较少时主图仍 `weight(1f)` 占满剩余

## 6. 系统返回动作

| 场景 | 行为 |
|---|---|
| 有上级 | 用户返回：安全 pop（`popRouteIfOnTop`；非裸 `popBackStack`）；移空/删除程序化离开见 [状态操作.md](状态操作.md)（Bug19） |
| 未保存草稿 | 不强制拦截（待定） |

## 7. 进入与退出

| 方向 | 说明 |
|---|---|
| 从哪里进入 | [主画面 · 列表项](../主画面/列表项.md) |
| 可前往 | 无 |
| 退出去向 | 回 `main`；**F30 / S9** 移动后无同状态全量剩余图 / 删除成功亦回 `main` |

## 8. 数据依赖

- `ImageDetailScreen` / `ImageDetailViewModel`
- `ImageRepository`：`rename` / `updateTags` / **`moveItems` / `deleteItems`（F30）**；`TagRepository`：库标签与标签模板
- `RenameTemplateRepository` + `RenamePatternApplier`（套用重命名模板）
- `ImageTagMetadata`；Coil + `filePath`
- 详见 [架构设计.md](../../架构设计.md)
