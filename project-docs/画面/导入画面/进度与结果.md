# 导入画面 · 进度与结果

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 导入画面（`import-images`） |
| 区域名称 | 进度与结果 |
| 对应 UI | 全屏 Loading 遮罩 + Snackbar |

## 2. 功能清单

- [x] 压缩开：超现行阈值则压缩（>2MB 或长边 >1920 → JPEG 85；**临时未定稿**，见 [待对应](../../../project-status/阶段/阶段4-维护与迭代/待对应.md)）；未超保留原样
- [x] 压缩关：**原样复制**，不压缩
- [x] 写入 `images/pending/` + Room（Pending）；合并默认标签
- [x] 进度文案「正在导入 x/y」
- [x] **F10**：全部成功：Snackbar「N 张导入完成」，**停留**导入画面空闲态，可继续选图
- [x] 部分/全部失败：失败明细弹窗（文件名 + 原因），支持单张/全部重试；「完成」仅关弹窗
- [x] **F10**：进入画面时清理 `pending/` 下无 DB 记录的孤儿文件
- [x] **F11**：开关开时：无原图名冲突的先导入；冲突暂停式逐张询问（跳过 / 导入 / 本次不再询问）

## 3. 用户操作

1. 选择完成后等待；成功停留并可再导；失败可重试或关弹窗后继续选图 / 自行返回
2. **F11**：若出现同名询问：选「跳过这张」不导入；「导入这张」仍新增一条；「本次不再询问」后本批剩余重名照常导入（不改全局开关）

## 4. UI 描述

- 导入中：半透明遮罩 + `CircularProgressIndicator` + 进度文字
- **F11** 询问中：`AlertDialog` 标题「发现同名图片」；正文含原图名；按钮「跳过这张」/「导入这张」/「本次不再询问」；底部提示「可在「设置 → 导入重名询问」中关闭」；**不可点外侧关闭**（`onDismissRequest` 空），须三选一
- 导入结束若有失败：AlertDialog 失败明细（文件名 + 原因分类 + 原始信息），每行「重试」，底部「全部重试」/「完成」
- 全部成功：Snackbar「N 张导入完成」（张数 = 实际导入成功数，不含跳过）

## 5. 数据 / 事件

- `ImageManager.prepareForImport(uri, compressEnabled)`；`repository.insert`（写入 `originalName`）
- `ImportDuplicateLogic.partition`：库内原图名（`trim` + 忽略大小写，含扩展名）+ 批内已分配无冲突项；规范化后为空串的永不冲突
- 失败明细：`ImportUiState.failedItems`（`FailedImportItem`：uri / displayName / errorKind / errorDetail）；`ImageManager.displayNameOf(uri)`
- 询问态：`ImportUiState.duplicatePrompt`（`originalName`）；`answerDuplicate(Skip|Import|SkipAskingRest)`
- 重试：`retryItem(uri)` / `retryAll()` / `dismissFailures()`；全部成功后发 `ImportUiEffect.ImportCompleted(n)`（不 pop）；重试路径不再询问
- 孤儿清理：`PendingOrphanCleaner` + `AppFileManager.cleanupPendingOrphans`（VM `init`）
- 偏好：`import_duplicate_ask_enabled`（默认 true；关则整批直导）
