# 导入画面 · 来源选择

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 导入画面（`import-images`） |
| 区域名称 | 来源选择 |
| 对应 UI | 压缩开关 + 相册 / 文件按钮 |

## 2. 功能清单

- [x] 「按规则压缩」开关（默认开；DataStore 记住）+ 规则说明
- [x] 「从相册选择」多选（Photo Picker）
- [x] 「从文件选择」多选（SAF）
- [x] **F3**：提示「同一张图重复导入会生成另一条记录」
- [x] **F1**：落盘名取自源显示名，主名清洗截断≤40，冲突加短后缀

## 3. 用户操作

1. （可选）切换是否压缩
2. 点选相册或文件 → 开始导入

## 4. UI 描述

- 上方：重复导入提示 + 开关 + 说明（现行：>2MB 或长边 >1920 → JPEG 85；**临时**，见 [待对应·压缩参数](../../../project-status/阶段/阶段4-维护与迭代/待对应.md)）
- 下方：两按钮垂直排列

## 5. 数据 / 事件

- `compressEnabled` ↔ DataStore；Activity Result → `importUris`

## 6. 待定事项

- 压缩阈值 / JPEG 质量是否正式定稿 → [阶段4 · 待对应](../../../project-status/阶段/阶段4-维护与迭代/待对应.md)
